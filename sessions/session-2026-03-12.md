# Session – 2026-03-12

## Topics covered
Set operators.

## What I understood
They are operators that combine the results sets of two or more selects into a single set result. 

UNION: Operator to combine the result of two or more selects into a single result, eliminating duplicates.

UNION ALL: Operator to combine the result of two or more selects into a single result, but do not eliminate duplicates (keeps all).

INTERSECT: An operator used to combine the results of two or more SELECT statements into a single result. However, it only combines and displays the results that appear in both sets.

MINUS: Operator to combine the results of two or more SELECT statements into a single result. However, it combines the results in such a way that it only includes the rows that appear in set1 but not in set2.
