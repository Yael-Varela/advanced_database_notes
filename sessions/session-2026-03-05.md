Analytic functions

## What I understood
OVER defines the scope of rows (called Window) that the function will consider for its calculation. It turns a regular function into an Analytic Function.

PARTITION allows us to select and ensure that the cumulative function only accumulates values ​​that are in the same section.

We also study "Window Ranges" which has diferent commands such as :
PRECEDING: It's for rows above or before the current row.
FOLLOWING: It's for rows below or after the current row.
CURRENT ROW: The row that is being processed at the moment.
UNBOUNDED: It's a command that acts as a "without limit", so it can go all the way to the end or to the beginning.


Note: To identify an analytic function, you must observe that it has the Over() command after the function.
