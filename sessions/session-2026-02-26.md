## Topics covered
SQL Aggregations.

## What I understood
These are SQL functions that act as calculation tools for the entire column.

SQL Agreggations:
SUM: Calculates the total sum of a numerical column.
COUNT: Counts the number of rows in a group, or the number of non null rows if a specific column is selected
AVG: Calculates the average value of a numerical column.
MAX and MIN: Find the highest and lowest values in a column.

As an additional note, we also learned "HAVING," which allows us to apply SQL aggregation functions only to the result of the conditional and not to the entire selection.
