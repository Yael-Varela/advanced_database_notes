DB Migrations and Object Relationship Mapping!

In this class we learned about data base migrations and ORM (Object-Relationship-Mapping). We learned about its importance for making changes to the database in an orderly and controlled manner, saving us from always having to make manual queries, as we can now modify the database with code.


## What I understood 
These are controlled changes that affect the database structure, keeping the database synchronized and allowing for rollbacks in case of emergency (something breaks or fails).

For ORM, the goal is to modify the database structure using code, classes, and objects instead of just SQL commands.
