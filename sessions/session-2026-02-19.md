Today's topic we covered various types of SQL JOINs. We explored the concepts of Inner Join, Left and Right Joins, Self Join and Cross Join.

## What I understood
First, a JOIN allow us to combine row data from two or more tables using a related column that normally is a unique identifier (key). There are multiple types of SQL JOINS. 

INNER JOIN (also called "JOIN"): Combine the tables and return only the rows that exist in both tables.

LEFT JOIN: Combine the tables but only return all rows from the left table and the matching rows from the right table, if there is no match the right side will be NULL.

RIGHT JOIN: Combine the tables but only return all rows from the right table and the matching rows from the left table, if there is no match the left side will be NULL.

SELF JOIN: A table that is joined to itself.

CROSS JOIN: Combine the tables but each element from one table will be combined with all the elements from the other table (like a matrix multiplication).
